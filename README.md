# DocAppoint - Doctor Appointment Manager

🌐 Live Site: https://docappoint-client-qc91.vercel.app

## Features

-  Browse top-rated doctors and view detailed profiles
-  Book, update, and delete appointments easily
-  Secure authentication with Google login and JWT
-  Manage personal profile with photo and name update
-  Search appointments by doctor name
-  Fully responsive design for all devices
-  Protected dashboard routes for logged-in users only
